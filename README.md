# Novsky desktop releases

Official installation packages and signed update manifests for Novsky. Application source code and customer data are not stored here.

The first public signed release is being prepared. There are no downloadable application releases or active update manifests yet.

- macOS Apple Silicon: arm64
- macOS Intel: x86_64
- Updater public key: `updater.pub`
- Release tags: `pilot-vVERSION` and `stable-vVERSION`
- Channels after the first signed release: `channels/pilot.json` and `channels/stable.json`

Published installers are versioned. App updates preserve the local workspace and are independent of updates to deployed agents.
